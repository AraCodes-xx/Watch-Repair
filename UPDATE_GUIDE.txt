DATABASE UPDATE REQUIRED
================================================================================

If you already created the database before these updates, you need to add
the watch_type column to the bookings table.

OPTION 1 - Run Migration Script:
1. Open phpMyAdmin: http://localhost:8080/phpmyadmin
2. Select "watch_repair_shop" database
3. Click "SQL" tab
4. Copy content from: database/add_watch_type.sql
5. Paste and click "Go"

OPTION 2 - Manual SQL:
Run this SQL command:
ALTER TABLE bookings ADD COLUMN watch_type VARCHAR(50) AFTER timeslot_id;

OPTION 3 - Fresh Install:
1. Drop existing database
2. Re-run database/schema.sql (includes watch_type column)

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Unknown column 'watch_type'" error
Solution: Run the database migration (see DATABASE UPDATE section above)

Problem: Calendar dates still misaligned
Solution: Clear browser cache (Ctrl+F5) and reload page

Problem: Can't access unified login
Solution: Check that Apache is running on port 8080

Problem: Old login pages redirect
Solution: This is normal - old URLs redirect to new unified login
